# `zizmor-http-cache`

[![docs.rs](https://img.shields.io/docsrs/zizmor-http-cache)](https://docs.rs/zizmor-http-cache)

The HTTP cache policy implementation is derived from
[`uv-client`](https://github.com/astral-sh/uv/tree/main/crates/uv-client/src/httpcache)
at commit `a600759b93304d64c9e0c003b6559841982d5b1d`. The derived portions are
